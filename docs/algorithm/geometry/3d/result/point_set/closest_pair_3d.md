三次元点集合から、ユークリッド距離が最小となる相異なるインデックスの対を求める。全点対を列挙するのではなく、$x$ 座標で分ける分割統治と、中央のスラブに対する $y$ 方向の帯分けと $z$ 順の線形走査を使う。固定次元の詰め込み上界（packing bound）により、各再帰段の結合処理は線形時間になる。

## API

- `closest_pair_3d(points)`: 距離最小の点対を `std::optional<ClosestPair3DResult>` で返す。`ClosestPair3DResult` は `first < second` を満たすインデックス `first`, `second` と距離 `distance` を持つ。同距離の対が複数あれば、インデックス対 `(first, second)` が辞書順最小のものを選ぶ。点が 2 個未満なら `std::nullopt` を返す。

完全に同一座標の点は事前のソートで検出し、その場合は距離 $0$ の対を直ちに返す。

## API別の時間計算量・空間計算量

| API | 時間計算量 | 空間計算量 |
| --- | --- | --- |
| `closest_pair_3d(points)` | 最悪 $O(N \log N)$ | $O(N)$ |

左右の再帰で得た距離の小さい方を $d$ とすると、中央面から距離 $d$ 以内の点だけを調べる。スラブを高さ $d$ 以下の $y$ 方向の帯に分け、各帯の内部と隣接する帯の間を $z$ 順に走査する。左右それぞれの点集合では任意の 2 点間距離が $d$ 以上なので、各 $O(d) \times O(d) \times O(d)$ の領域に入る点の数は定数であり、各再帰段での比較回数は $O(N)$ である。点数 $32$ 以下の部分問題は全対比較で解く。

## 注意点

- 座標は有限でなければならず、違反した場合は `std::invalid_argument` を送出する。
- 内部の距離比較は、仮数と 2 進指数を分離した表現で行う。有限座標どうしの差やユークリッド距離が `long double` の最大値を超えても、比較と枝刈りはオーバーフローしない。
- 返す `distance` 自体が `long double` で表せない場合、その値は正の無限大になる。
- ユークリッドノルムの仮数部分の計算には `std::hypot` を使い、平方和のオーバーフローを避ける。
