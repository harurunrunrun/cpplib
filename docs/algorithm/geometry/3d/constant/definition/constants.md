## API

- `GEOMETRY3D_EPS`: 浮動小数点判定に用いる絶対許容誤差。
- `GEOMETRY3D_PI`: 長倍精度浮動小数点数の円周率。

## API別の時間計算量・空間計算量

- 全操作: 時間・追加領域 $O(1)$。

## 注意点

許容誤差を用いるかどうかは個別APIの契約に従う。
