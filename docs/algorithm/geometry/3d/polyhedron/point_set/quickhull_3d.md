## API

- `quickhull_3d(points)`: 点集合の三次元凸包を、外向き三角形面からなる `ConvexPolyhedron3` として返す。

重複点は 1 つにまとめる。入力が空、同一点のみ、共線、共面の場合（および初期四面体を作れない場合）は `convex_hull_3d` に委譲し、`affine_dimension` がそれぞれ $-1, 0, 1, 2$ の退化した凸包を返す。

## アルゴリズム

内部の各面は、隣接面・担当する外側点集合（outside set）・最遠点を保持する。外側点を持つ候補面をキューで管理し、展開点から見える連結な面領域だけを隣接関係に沿って探索する。削除される面が担当していた点だけを新しい horizon cone の面へ再配置するため、展開ごとに「全生存面 $\times$ 全入力点」を走査することはない。

各点は同時には 1 つの面の outside set にだけ所属する。面の展開では、可視領域に含まれる面の outside set の和集合だけが再判定の対象になる。

## API 別の時間計算量・空間計算量

- 点数を $N$、出力面数を $K$ とする。座標順の整列に $O(N \log N)$、horizon の展開を含む決定的な幾何処理に最悪 $O(N^2)$ 時間を使う。入力点の並びは内部で辞書順に固定され、展開点も決定的に選ぶため、入力と独立な乱択順を仮定した期待時間 $O(N \log N + K)$ は保証しない。
- 生成途中の削除済み面を含む面数を $T$ とすると、領域は $O(N + T)$ である。通常は $O(N + K)$、最悪は $O(N^2)$。
- 面の隣接辺の照合はハッシュ表による期待 $O(1)$、候補面の追加と取り出しは償却 $O(1)$ である。このハッシュ表の期待値は辺の照合だけに関するもので、決定的な horizon 展開の最悪 $O(N^2)$ を期待 $O(N \log N)$ に変えるものではない。

## 注意点

- 可視性の判定には適応的な `adaptive_orient3d` を使う。
- NaN または無限大を含む点があれば `std::invalid_argument` を送出する。
- 入力は値渡しであり、呼び出し元の点列は変更しない。
- 点を辞書順に整列し、最遠点の距離が等しい場合は点番号で、候補面は追加順で決めるため、同じ入力に対する頂点列と面列は決定的である。
