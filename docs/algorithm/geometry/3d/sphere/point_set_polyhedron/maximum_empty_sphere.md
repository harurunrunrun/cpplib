中心を有界な凸多面体の中に制約したうえで、サイト（与えられた点）を内部に含まない半径最大の球を求める。

## API

- `maximum_empty_sphere(sites, bounds)`: 中心が `bounds` に属する点のうち、最も近いサイトまでの距離を最大化する点を求め、その点を中心、その距離を半径とする `Sphere3` を返す。`sites` は `std::vector<Point3>`、`bounds` は `ConvexPolyhedron3` である。
  - 候補として、内部の Voronoi 頂点、境界面と Voronoi 辺の交点、境界辺と Voronoi 面（ridge）の交点、境界の頂点を評価する。
  - サイトが三次元に広がっている場合は、各候補に接続する Delaunay サイトを保持しておき、その 1 点までの距離を半径として使う。

## API別の時間計算量・空間計算量

重複除去後のサイト数を $S$、境界の頂点数・辺数・面数を $V, E, F$、Delaunay 四面体の数を $T$、相異なる有限 Voronoi 頂点の数を $U$、Voronoi 面（ridge）の数・Voronoi 辺の数を $R, A$ とする。
また、境界頂点を含むセルへ Delaunay の隣接関係をたどって移動するときの半空間判定の総数を $W$、境界辺と ridge の交点候補が実際にその ridge 上にあるかを確認する半空間判定の総数を $P$ とする。

| サイトのアフィン次元 | Voronoi 図構築後の候補評価の時間 | 追加の空間計算量 |
| --- | --- | --- |
| 3 | $O(T + W + UF + ER + P + FA + F \log F)$ | $O(S + T + R + A + U + V + E + F)$ |
| 2 以下 | $O(VS + ES^3 + FS^4 + F \log F)$ | $O(S + V + E + F)$ |

これとは別に、三次元 Voronoi 図の構築にかかる時間・空間が必要である。

サイトが三次元に広がっている場合、列挙・検査される候補の数を $C = O(V + U + ER + FA)$ とすると、候補の半径評価は合計 $O(C)$ であり、候補ごとに全サイトを走査する $O(CS)$ の処理は発生しない。
有限 Voronoi 頂点は接続するセルから、Voronoi 辺・ridge 上の候補はその辺・ridge を定義する Delaunay サイトから半径を得る。境界頂点だけは、Voronoi セル間を「より近い隣接サイト」へ移動していくことで所属するサイトを特定する。$W$ と $P$ はこの所属確認のコストを上の表に明示したものである。

サイトが三次元に広がっている場合は Voronoi 図の接続関係だけを走査し、サイトの全ペア・全 3 つ組の列挙は行わない。
アフィン次元が 2 以下の場合はこのライブラリが Voronoi 図の接続関係を保持しないため、正しさを保つための代替手段として、境界辺ではサイトの全ペア、境界面では全 3 つ組を列挙する。

## 注意点

- 球の中心だけを `bounds` 内に制約する。球全体を `bounds` 内に収める API ではない。
- `bounds` は外向きの三角形面を持つ、空でない三次元の凸多面体でなければならない。
- サイトが空の場合、サイトの座標が有限でない場合、`bounds` が三次元でない（`affine_dimension != 3` または頂点が空の）場合は `std::invalid_argument` を送出する。
- 候補が 1 つも得られなかった場合は `std::domain_error` を送出する。
- 最大となる中心が複数ある場合は、そのうち列挙順で最初のものを返す。
- `bounds` への包含は外向きの面に対する適応的な述語で判定し、辺・面・サイトの差は局所的なスケールで正規化する。境界面との交点は、その三角形面に対する重心座標でも所属を確認する。補助的な交点が `long double` で表現できない場合は、その候補を除外する。
- サイトが三次元に広がっている場合の境界辺の候補では、二等分面全体ではなく実際の Voronoi 面（ridge）との交点だけを採用するため、接続するセルの全半空間を検査する。
- 最も近いサイトまでの真の距離が `long double` で表現できない場合は `std::overflow_error` を送出する。
