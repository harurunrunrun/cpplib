凸とは限らない単純多角形を直線で切断し、直線の左側と右側の部分をそれぞれ求める。

## API

```cpp
PolygonLineCutResult polygon_cut(
    const std::vector<Point>& polygon,
    const Line& line
);
```

## 引数

`polygon` には単純多角形の頂点を周回順に並べた列を、`line` には向きを持つ非退化な直線を渡す。多角形は凸でなくてもよい。

## 戻り値

`left` は多角形と直線の左側の閉半平面との共通部分、`right` は右側の閉半平面との共通部分である。それぞれを反時計回りの連結成分の列 `std::vector<std::vector<Point>>` として返すため、切断後の共通部分が非連結でも全成分を保持する。

## 時間計算量

頂点数を $N$ とすると、最悪時間計算量は $O(N \log N)$、戻り値を除く追加領域は $O(N)$ である。境界辺の登録には順序付き集合（`std::set`）を、切断直線上の交点の整列にはソートを使う。直線上の各区間が多角形の内部にあるかどうかは、境界の交差から得た偶奇を一度の走査で更新して判定し、区間ごとに $O(N)$ の点包含判定を行うことはしない。

## 注意点

- 自己交差や自己接触を持たない頂点列であることを前提とし、この条件は検査しない。
- 退化した直線には `std::invalid_argument` を送出する。
- 切断後の面の向きは、原点を移動した後の座標の大きさの 2 乗をスケールとする符号付き面積で判定するため、微小でも非退化な面は保持する。
- 退化判定に該当しない範囲では、`line.b - line.a` を正の定数倍しても結果は変わらない。
