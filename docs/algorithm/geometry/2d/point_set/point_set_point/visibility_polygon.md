単純多角形の内部にある観測点から、遮られずに見える領域の境界を求める。

## API

~~~cpp
std::vector<Point> visibility_polygon(
    const std::vector<Point>& polygon,
    const Point& observer
)
~~~

可視領域の頂点を、観測点のまわりの反時計回りの順に返す。入力 `polygon` は時計回り・反時計回りのどちらでもよい。境界は不透明で、各方向について観測点に最も近い境界までを可視とする。遮蔽が切り替わる半直線上では、同じ半直線上の近い点と遠い点の両方が結果に現れることがある。

## アルゴリズム

観測点から見た頂点の方向でイベントを作り、隣り合うイベントの間の角度区間（セル）を葉とするセグメント木に、各辺が覆う角度区間を登録する。単純多角形の辺同士が交差しないことを利用して、各ノードには最も手前の辺を 1 本だけ保持し、各イベントの直前・直後のセルで最も手前の辺を求める（オフラインの下側エンベロープ）。イベントの方向そのものについては、そのイベントに接続する辺と直前・直後の最前辺だけを比較する。入力に依存する微小な角度のずらしは用いない。

## 時間計算量

頂点数を $N$、戻り値の点数を $K$ とする（$K \le 3N$）。

- 単純性の検査: $O(N \log (N + 1))$。Bentley–Ottmann の平面走査を使い、隣接辺同士の $N$ 個の交点に加えてもう 1 件見つけた時点で打ち切る。
- 角度イベントの構築と可視境界の計算: $O(N \log (N + 1) + K)$。
- 全体: $O(N \log (N + 1) + K)$。

現在の API は非単純多角形を検出するため、入力が単純であることを呼び出し側が保証していても検査は省略しない。

## 空間計算量

$O(N + K)$。

## 注意点

- `polygon` は、有限座標の $3$ 頂点以上からなり、面積が $0$ でない単純多角形でなければならない。退化辺・自己交差・隣接辺の重なりがあれば `std::invalid_argument` を送出する。
- `observer` は `polygon` の厳密な内部にある有限座標の点でなければならない。境界上または外部にあれば `std::invalid_argument` を送出する。
- 同じ半直線上に複数の頂点があっても、1 つの角度イベントとして処理する。観測点から放射状に伸びる辺はイベント上でのみ比較し、隣接する開いた角度区間で有効な辺には含めない。
- 返す点はすべて入力 `polygon` の境界上にある。遮蔽の境目では、凹頂点から延ばした半直線と別の辺との交点も含まれ得る。
- 計算は `long double` による近似計算である。方向の差・辺の長さ・交点間の距離が `GEOMETRY_EPS` または機械精度と同程度なら、同じ方向のイベントや同一点として併合されることがある。
- 連続する戻り値の点を併合する距離のしきい値は、絶対誤差 $8 \cdot \varepsilon$（$\varepsilon$ は `GEOMETRY_EPS`）と、入力座標の大きさおよび観測点からの距離に応じた機械丸め誤差の和である。
